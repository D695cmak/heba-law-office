طريقة التشغيل:
1) فك الضغط.
2) افتح ملف HTML في Chrome أو أي متصفح حديث.
3) بيانات الدخول التجريبية:

مهم:
هذه النسخة تعمل محليًا باستخدام LocalStorage لتجربة الواجهة والوظائف.
لا تستخدمها لتخزين بيانات عملاء حقيقية أو حساسة.
للاستخدام الفعلي يلزم Backend وقاعدة بيانات واستضافة HTTPS ومصادقة وصلاحيات وتشفير ونسخ احتياطية ومراجعة أمنية.
